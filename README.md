# YUNAN GOLD INTELLIGENCE — Private Website v1.1

لوحة ويب عربية RTL مبنية بـ Streamlit، مع بوابة تسجيل دخول خاصة. يمكن فتحها من متصفح الهاتف أو الكمبيوتر بعد نشرها على خدمة استضافة.

## ما يتضمنه الموقع
- لوحة نظرة عامة مخصصة لتحليل XAUUSD.
- عوائد الخزانة الأمريكية 2Y/5Y/10Y/20Y/30Y، والعائد الحقيقي 10Y وتعويض التضخم 10Y عبر FRED عند توفير API key.
- تقويم اقتصادي أمريكي اختياري عبر Trading Economics.
- أقسام COT وOpen Interest وDXY والتحليل الفني وتجهيزات الربط المستقبلي مع TradingView.
- إعداد المنطقة الزمنية، وبيان واضح عند عدم توفر مصدر البيانات؛ لا يتم اختلاق أرقام.
- تسجيل دخول بكلمة مرور محفوظة في Secrets، وليس في كود الموقع.

## النشر كموقع خاص
1. فك ضغط الملف وارفع محتويات المجلد إلى مستودع GitHub خاص.
2. افتح Streamlit Community Cloud واربطه بالمستودع، ثم اختر `app.py` كملف التشغيل.
3. في إعدادات التطبيق، أضف هذه القيم ضمن **Secrets** (استبدل القيم بأخرى خاصة بك):

```toml
APP_USERNAME = "اكتب_اسم_مستخدم_خاص"
APP_PASSWORD = "ضع_هنا_كلمة_مرور_قوية_وفريدة"
FRED_API_KEY = ""
TRADING_ECONOMICS_API_KEY = ""
```

4. انشر التطبيق. لن تظهر لوحة الموقع قبل إعداد APP_USERNAME وAPP_PASSWORD.
5. لا تضع الأسرار في مستودع GitHub أو ترسل كلمة المرور في محادثة عامة. احفظها في مدير كلمات مرور.

## ملاحظات مهمة
- هذه الحزمة جاهزة للرفع والنشر، لكنها **ليست رابطًا منشورًا**؛ يلزم إنشاء الاستضافة من حسابك. لا يمكن إنشاء رابط عام فعلي من ملف ZIP وحده.
- تسجيل الدخول هنا بوابة على مستوى التطبيق؛ استخدم مستودعًا خاصًا، HTTPS من مزود الاستضافة، وكلمة مرور قوية. للحماية الحساسة جدًا، أضف مزود هوية/SSO أو حماية على مستوى الاستضافة.
- لم يتم التحقق من مفاتيح API الحقيقية. اختبر كل مصدر بعد إضافته. قد تتطلب بيانات التقويم اشتراكًا أو صلاحيات مدفوعة؛ لا تشترِ اشتراكًا قبل التحقق من التكلفة.
- أقسام COT وOpen Interest وDXY والأسعار الحية وTradingView ما زالت تحتاج ربطًا بمصادر مناسبة؛ تعرض الواجهة حالتها بوضوح ولا تعتبرها بيانات حية حاليًا.
- هذه أداة بحث وليست توصية مالية.

## تشغيل محلي للمطور
Python 3.10+، ثم:

```bash
pip install -r requirements.txt
streamlit run app.py
```
